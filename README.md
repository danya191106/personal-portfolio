# 🌐 Personal Portfolio

A personal portfolio website designed to showcase my profile, skills, projects, and contact information as a Computer Science Engineering student.

## 🌐Live Demo  https://danyaloganathan-portfolio.netlify.app

## 📌 Project Overview

This portfolio website provides a simple and professional way to introduce myself, showcase my technical skills, highlight my projects, and provide contact links.

The website is built using HTML and CSS with a responsive layout that adapts to different screen sizes.

## 🛠️ Technologies Used

- HTML5
- CSS3

## ✨ Features

- Responsive personal portfolio website
- Sticky navigation bar
- Home section
- About Me section
- Skills section
- Projects section
- Contact section
- Profile illustration
- Responsive layouts for desktop, tablet, and mobile screens
- Hover effects and smooth scrolling
- Email, LinkedIn, and GitHub links

## 📱 Responsive Design

The portfolio is designed to work across different screen sizes using CSS media queries.

The layout adjusts the navigation, skill cards, project card, content spacing, and other elements for smaller screens.
